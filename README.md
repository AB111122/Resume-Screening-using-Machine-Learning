<img width="476" height="665" alt="image" src="https://github.com/user-attachments/assets/9ec81ff0-1712-468e-a01f-ed8fe4aba9b0" /># AI Resume Screening & Job Recommendation System

An intelligent Resume Screening and Job Recommendation web application that automates resume analysis using Machine Learning and Natural Language Processing (NLP).
The system allows users to upload resumes in PDF format, extracts important candidate information, predicts the most suitable job category, recommends relevant job roles, and provides an ATS-based resume evaluation.

---

## Features

- Upload Resume (PDF)
- Resume Text Extraction
- Resume Classification
- Job Recommendation
- Resume Parsing
- Skill Extraction
- Email & Phone Number Extraction
- ATS Resume Score
- Clean Web Interface using Flask

---

## Tech Stack

### Backend

- Python
- Flask

### Machine Learning

- Scikit-Learn
- Random Forest Classifier
- TF-IDF Vectorizer

### NLP

- Regular Expressions (Regex)
- Text Preprocessing

### Libraries

- Pandas
- NumPy
- PyPDF2
- Pickle

### Frontend

- HTML
- CSS

---

## Project Workflow

1. Upload Resume (PDF)
2. Extract Resume Text
3. Clean & Preprocess Text
4. Convert Text using TF-IDF
5. Predict Resume Category
6. Recommend Suitable Job Roles
7. Extract Candidate Information
8. Calculate ATS Score
9. Display Results

---

## Extracted Information

- Name
- Email Address
- Phone Number
- Skills
- Education
- Resume Category
- Recommended Jobs
- ATS Score
